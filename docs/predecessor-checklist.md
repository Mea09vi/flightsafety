# รายการที่ต้องขอและถามจาก FSO คนเดิม

พิมพ์ไปใช้ระหว่างคุยได้ ข้อที่มีเครื่องหมาย ★ ต้องได้ก่อนจบการคุย

## ก. ไฟล์ที่ต้องขอ (ขอเป็นไฟล์ดิจิทัล ถ้าเป็นกระดาษขอยืมไปสแกน)
- [ ] ★ รายงานอุบัติเหตุและอุบัติการณ์ทั้งหมดที่มี ย้อนหลังให้ได้มากที่สุด แยกตามฝูง
- [ ] ★ ผลการสอบสวน + ข้อเสนอแนะ + **สถานะการแก้ไข** (ปิดแล้ว/ยังค้าง)
- [ ] ★ แบบฟอร์มรายงานที่ ทอ. ใช้ จะดูว่ามีช่องข้อมูลอะไรและจัดหมวดสาเหตุอย่างไร
- [ ] Hazard report / near-miss / รายงานนกชน (bird strike)
- [ ] รายการหรือแผนที่อันตรายในพื้นที่ (สายไฟแรงสูง เสาสูง พื้นที่นกชุกชุม) ทั้งในสนามและ LZ/พื้นที่ฝึกที่ใช้บ่อย
- [ ] ประกาศและข่าวสารนิรภัยจาก สนภ.ทอ. ที่เคยได้รับ
- [ ] สถิติสรุปรายปี / slide ประชุมนิรภัยประจำเดือน
- [ ] ระเบียบและคำสั่ง ทอ. ว่าด้วยการนิรภัยการบิน โดยเฉพาะ**ข้อกำหนดการเผยแพร่ผลสอบสวน**
- [ ] ★ **แบบฟอร์ม brief ก่อนบินที่แต่ละฝูงใช้อยู่ตอนนี้** (แอปต้องเสียบเข้าไปในขั้นตอนนี้ได้พอดี)
- [ ] แผนงานนิรภัยประจำปี และรายชื่อนายทหารนิรภัยฝูง

## ข. คำถาม
**เรื่องข้อมูล**
1. ★ มีเคสประมาณกี่เคส ช่วงปีไหน เก็บไว้ที่ไหน (ตู้เอกสาร / ไฟล์ / ระบบของ ทอ.)
2. ★ ทอ. จัดหมวดสาเหตุแบบไหน (HFACS, 5M, หรือระบบของ ทอ. เอง) ทำครบทุกเคสหรือไม่
3. ★ ข้อมูลส่วนไหนห้ามเผยแพร่ แม้แต่ภายในหน่วย และใครเป็นผู้อนุมัติ
4. มีเคสของ S-70i หรือ H135 (แบบใหม่) บ้างหรือยัง

**เรื่องหน้างาน**
5. ★ ปัญหาที่เกิดซ้ำบ่อยที่สุด 3 อันดับของแต่ละฝูงคืออะไร
6. มีเคสไหนที่ "คนในหน่วยยังพูดถึงจนทุกวันนี้" บ้าง
7. ตอนนี้รับ hazard report ทางไหน ทำไมคนถึงรายงาน หรือทำไมถึงไม่รายงาน
8. เคยมีใครพยายามทำ lesson learned ลักษณะนี้มาก่อนไหม ทำไมถึงไม่ได้ทำต่อ
9. การ brief ก่อนบินจริงใช้เวลากี่นาที ใครเป็นคนพูด ในห้องมีจอฉายไหม

**เรื่องคน**
10. ผู้ติดต่อที่ สนภ.ทอ. · นายทหารนิรภัยฝูง 201/202/203 · ฝ่าย QA ช่าง
11. งานค้างที่ส่งต่อมาให้ (การสอบสวนที่ยังไม่ปิด หรือข้อเสนอแนะที่ยังไม่ได้ทำ)
