# Schema ของ Google Sheet (ฉบับร่าง)

1 Sheet มี 2 แท็บข้อมูลหลัก ส่วนค่าที่ใช้ใน dropdown ดึงมาจากแท็บ taxonomy
(นำเข้าจาก `../taxonomy/*.csv`) ช่องที่รับหลายค่าให้คั่นด้วย `;`

## แท็บ `cases` — 1 แถว = 1 การ์ด
| คอลัมน์ | บังคับ | ค่า / ตัวอย่าง | หมายเหตุ |
|---|---|---|---|
| `id` | ✓ | `INTL-0001`, `W2-0001`, `RTAF-0001` | prefix = แหล่งที่มา |
| `source` | ✓ | `W2` / `RTAF` / `INTL` | |
| `type` | ✓ | `accident` / `incident` / `hazard` / `area_hazard` / `notice` | |
| `year` | ✓ | `2016` | ไม่ใส่วันที่แน่นอน |
| `title` | ✓ | ใบพัดหลักหลุดจาก MGB ขณะบินเดินทาง | หัวข้อสั้น |
| `aircraft` | ✓ | `H225M;S-92` หรือ `ALL` | taxonomy `aircraft.csv` |
| `mission` | ✓ | `SAR;HOIST` หรือ `ALL` | taxonomy `mission.csv` |
| `environment` | ✓ | `NIGHT;OVERWATER` หรือ `ALL` | taxonomy `environment.csv` |
| `phase` | | `HOVER;APPROACH` | taxonomy `phase.csv` |
| `area_id` | | `LZ-001` | อ้างอิงแท็บ `areas` · เคส INTL ไม่ใช้ |
| `hfacs` | | `AE105;PC102;SI004` หรือ `AE100` | taxonomy `hfacs.csv` (DoD HFACS 8.0) ใส่แค่ระดับหมวด (`level=category`) ก่อนก็ได้ |
| `severity` | | ระดับความรุนแรงตามที่ ทอ. กำหนด | รอดูแบบฟอร์ม ทอ. — เผยแพร่ได้โดยยังไม่ใส่ |
| `summary` | ✓ | ไม่เกิน 3 บรรทัด | |
| `factors` | ✓ | ปัจจัยสาเหตุ | |
| `actions_today` | ✓ | 2–3 ข้อ ขึ้นบรรทัดใหม่ทีละข้อ | **หัวใจของการ์ด** |
| `brief_question` | ✓ | ถ้า … ใครทำอะไร | |
| `ref` | ✓ | URL หรือเลขที่หนังสือ | |
| `status` | ✓ | `draft` / `published` / `cut` | build รวมเฉพาะ `published` (`--include-draft` รวม `draft` ด้วย) · `cut` = FSO ตัดทิ้ง แถวยังอยู่แต่ไม่ขึ้นแอป |
| `reviewed` | | `2026-10-15` | วันที่ FSO ตรวจล่าสุด |

**กติกาการจับคู่ (ร่าง):** การ์ดจะแสดงเมื่อ `aircraft`, `mission` และ `environment` ตรงกับที่เลือก
(ค่า `ALL` ตรงกับทุกตัวเลือก) จากนั้นเรียง: เคส `W2` ขึ้นก่อนเสมอ → จำนวนตัวกรองเสริมที่ตรง → ความเฉพาะเจาะจง
(ตรงจริงไม่ผ่าน `ALL`: แบบ ฮ. > ภารกิจ > สภาพแวดล้อม) → `RTAF` > `INTL` → ปีใหม่กว่าขึ้นก่อน
แสดง 3 การ์ดแรก และกด "ดูเพิ่ม" ได้

## แท็บ `areas` — อันตรายประจำพื้นที่
| คอลัมน์ | บังคับ | ตัวอย่าง |
|---|---|---|
| `area_id` | ✓ | `LZ-001` |
| `name` | ✓ | สนามบินโคกกะเทียม |
| `lat`, `lon` | ✓ | `14.87`, `100.66` (ทศนิยม) |
| `hazard` | ✓ | `WIRE` / `OBSTACLE` / `BIRD` / `TERRAIN` / `OTHER` |
| `detail` | ✓ | สายไฟแรงสูงพาดผ่านแนว approach ด้านตะวันออก สูงประมาณ 30 ม. |
| `review_by` | | `2027-04-01` (วันที่ต้องตรวจซ้ำ) |

ปุ่มพิกัดในแอปจะเปิดลิงก์ `geo:` หรือ Google Maps ภายนอก (ไม่โหลดแผนที่ในแอป)

## สิ่งที่ build script ตรวจก่อนเข้ารหัส
- ช่องบังคับครบ และค่า tag ทุกตัวอยู่ใน taxonomy
- `id` ไม่ซ้ำ
- มีคำที่อาจระบุตัวตนหรือไม่ (ยศ + ชื่อ, หมายเลขเครื่อง `\d{5}`, วันที่เต็ม) → แสดงคำเตือนแต่ไม่บล็อก
  (ไม่ตรวจช่อง `ref` เพราะ URL รายงานต่างประเทศมีเลขทะเบียนและวันที่อยู่แล้ว)
