# แหล่งอ้างอิงเคส INTL

ทุกเคสใน `data/intl_seed.csv` ตรวจจากรายงานฉบับสมบูรณ์ หรือหน้าสรุปทางการของหน่วยงานสอบสวนเท่านั้น
ห้ามเพิ่มข้อเท็จจริงที่ไม่อยู่ในรายงาน ถ้าไม่แน่ใจให้ตัดออก

**ข้อควรรู้**
- URL ใน `ref` มีเลขทะเบียนหรือวันที่ปนอยู่ ซึ่งเลี่ยงไม่ได้ เพราะเป็นที่อยู่ของรายงานต้นฉบับ
  build script จึงต้อง**ข้ามช่อง `ref`** ตอนตรวจ PII ส่วนเนื้อหาการ์ดต้องไม่มีทะเบียน/วันที่
- 21 ต.ค. 2569 ผู้ใช้มอบให้ Claude ตรวจทั้งชุดแทน FSO: เทียบรายงานต้นฉบับทุกเคส ปรับภาษาตาม `intl-wording.md`
  และทบทวน `hfacs` ตามกฎ ก–ฑ → 316 เคส เป็น `published` 314 เคส, `draft` 2 เคส (0039 เปิดต้นฉบับไม่ได้, 0289 มีแค่ข่าวแจก)
  ผลตรวจเคสเดิม 281 เคส: ตรวจกับต้นฉบับได้ครบ 266 · บางส่วน 14 · เปิดไม่ได้ 1
  ยังไม่ได้ใส่ `severity` (รอแบบฟอร์มของ ทอ.) · เหตุผล `hfacs` รุ่นแรกอยู่ใน `hfacs-draft.md`
- รายงานที่ไม่ใช่ภาษาอังกฤษ (ฝรั่งเศส ญี่ปุ่น ไทย) แปลหรือสรุปเป็นไทยจากต้นฉบับ เก็บเฉพาะข้อเท็จจริงที่รายงานเขียน
- เคสที่ใช้แบบ ฮ. ตระกูลเดียวกัน (EC225/AS332/Puma → H225M, UH-60 → S-70i, EC135 → H135,
  CH146 Griffon → Bell 412EP, CH148 Cyclone → S-92) ระบุไว้ในชื่อการ์ดแล้ว
- แบบ ฮ. ที่ไม่มีใน บน.2 (Chinook, Sea King, AW101, AW169, AS350 ฯลฯ) ติด `aircraft=ALL`
  และใช้เฉพาะเมื่อบทเรียนเป็นเรื่องภารกิจ/สภาพแวดล้อม/CRM ที่ใช้ได้กับทุกแบบ
- ป้ายชื่อหน่วยงานบนปุ่ม "อ่านรายงานต้นฉบับ" มาจาก `REF_HOSTS` ใน `tools/build_data.py`

## ชุดที่ 3 (28 เคส, BEA-É ฝรั่งเศส, ภาษา FR, 13 ต.ค. 2569)

BEA-É (Bureau enquêtes accidents pour la sécurité de l'aéronautique d'État) สอบสวนอากาศยานของรัฐฝรั่งเศส
ทั้งทหารและพลเรือน รายงานเป็นภาษาฝรั่งเศส ใช้ส่วน résumé + "causes" + "facteurs contributifs" แล้วแปลเป็นไทย

- ตัวอักษรหน้าเลขรายงานบอกหน่วยผู้ใช้ เช่น A = กองทัพอากาศ, T = กองทัพบก (ALAT), M = กองทัพเรือ,
  G = Gendarmerie, S = Sécurité civile (กู้ภัยพลเรือน)
- Cougar / Puma / Caracal ติด `aircraft=H225M` และเขียน "(ตระกูลเดียวกับ H225M)" ในชื่อการ์ด
- EC145 / EC120 / NH90 / AS350 / Fennec / Alouette III ติด `ALL`
  เลือกเฉพาะเคสที่บทเรียนเป็นเรื่อง hoist, CRM, ภูเขา, ทะเล หรือการฝึก ซึ่งใช้ได้กับทุกแบบ
- ใช้คำว่า "ช่างอากาศ (MOB)" แทน hoist operator / mécanicien opérateur de bord ให้ตรงกับการ์ดเดิม
- ลิงก์ใน `ref` ชี้ไปที่ PDF บน defense.gouv.fr ป้ายบนปุ่มคือ "BEA-É France"
