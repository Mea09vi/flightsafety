# ภาษาในเคส INTL — แนวเขียนแบบภาษาราชการ ทอ.

ผู้ใช้ (FSO บน.2) ตัดสิน 21 ต.ค. 2569 ให้เคส INTL ใช้ภาษาแบบเดียวกับรายงานเหตุของกองบินในปัจจุบัน
เพื่อให้นักบินอ่านแล้วคุ้น และให้ Claude ตรวจเองทั้งชุด (ไม่ต้องรอ FSO ไล่ตรวจถ้อยคำ)
ไฟล์นี้มีแต่กฎการใช้คำ ไม่มีข้อความจากรายงานของหน่วย

**ห้ามเปลี่ยนข้อเท็จจริง** — ตัวเลข ลำดับเหตุการณ์ ระดับความแน่นอน และใครทำอะไร ต้องตรงกับรายงานต้นฉบับ
เปลี่ยนได้แค่ถ้อยคำ หน่วย และการเรียกตำแหน่ง

## หน่วยวัด
| เดิม | ใช้ |
|---|---|
| ft | ฟุต (3,000 ฟุต — ใส่จุลภาคหลักพัน) |
| kt / kts | นอต |
| nm / NM | ไมล์ (ไมล์ทะเล) — ครั้งแรกในเคสเขียน "ไมล์ทะเล" ถ้าต้องแยกจากไมล์บก |
| m / ม. | เมตร |
| ° | องศา (ทิศทางเขียน "ทิศ 270 องศา") |
| ชม. | ชั่วโมง (ชั่วโมงบิน 1,200 ชั่วโมง) |
| ราว | ประมาณ |

## การเรียกตำแหน่ง
- ลูกเรือสองนักบิน: กัปตัน / PIC → **นักบินที่ 1 (นบ.1)** ครั้งแรก แล้วใช้ นบ.1 ต่อ · นักบินผู้ช่วย / FO / co-pilot → **นักบินที่ 2 (นบ.2)**
- นักบินคนเดียว: **นักบิน** (ไม่ต้องใส่หมายเลข)
- ครูการบิน → **ครูการบิน (คบ.)** · ศิษย์การบิน → ศิษย์การบิน
- ลูกเรือที่ทำงานบนเครื่อง (hoist operator, crew chief, flight engineer, aircrewman) → **ช่างอากาศ**
- ช่างซ่อมบำรุงภาคพื้น → **ช่างอากาศยาน** · หน่วยซ่อมบำรุง → ฝ่ายซ่อมบำรุง
- นักบินที่ทำหน้าที่บังคับ (PF) / ดูแลระบบ (PM) → คงคำอังกฤษ PF / PM ได้ ครั้งแรกเขียน "นักบินผู้บังคับ (PF)"
- ห้ามใส่ชื่อบุคคลทุกกรณี

## คำศัพท์การบิน
- คำอังกฤษที่ใช้กันใน ทอ. เขียนตัวพิมพ์ใหญ่ต้นคำ (Title Case): Approach, Final, Short Final, Go Around, Hover,
  Hover Taxi, Air Taxi, Autorotation, Checklist, Roll On Landing, Run-on Landing, Flare, Downwash, Brownout,
  Whiteout, Vortex Ring State, Dynamic Rollover, Inadvertent IMC, Pre-flight Check, Post Flight Check
- ชื่อระบบและพารามิเตอร์คงตัวพิมพ์ตามคู่มือ: NR, NG, TGT, TOT, Q, FADEC, AFCS, EGPWS, HTAWS, NVG, SAS
- เฮลิคอปเตอร์ → **เฮลิคอปเตอร์** ในบทนำ ครั้งต่อไปใช้ **ฮ.** ได้ · เครื่องบิน → อากาศยาน / เครื่อง
- ลงจอดที่สนามบิน → **ลงสนาม** · ลงนอกสนาม → ลงจอด · ลงฉุกเฉิน → **ลงฉุกเฉิน** (Forced / Precautionary Landing)
- ขัดข้อง / ใช้การไม่ได้ / ชำรุด (แทน "เสีย", "พัง")
- หอบังคับการบิน (ไม่ใช่ "หอควบคุม")

## สำนวน
- เปิดเรื่องที่ฉาก เช่น "นักบินที่ 1 และนักบินที่ 2 นำ ฮ. … ทำการฝึกบิน…" เวลาเขียน "เวลาประมาณ 10.30 น. (เวลาท้องถิ่น)"
  เฉพาะเมื่อรายงานให้ไว้ · เคส INTL ยังเก็บแค่ปี ไม่ใส่วันที่เต็มและทะเบียนเครื่อง (เกณฑ์ข้อมูลสาธารณะเดิม)
  ช่วงเวลาอย่างเดือนหรือฤดูใส่ได้ถ้าเกี่ยวกับเหตุ (เช่น ฤดูหนาว หิมะ)
- ใช้กริยาราชการ: **ทำการ** (ฝึกบิน / บิน), **ปฏิบัติ** (ภารกิจ / ตามขั้นตอน), **ดำเนินการ**, **ตรวจสอบ**
- การตรวจเครื่อง: "ตรวจสอบสภาพ ฮ. ตามคู่มือ ไม่พบข้อขัดข้อง"
- ไม่ใช้ภาษาพูดหรือสำนวนข่าว ("พุ่ง", "ดิ่ง", "หวุดหวิด", "โชคดีที่")
- ประโยคสั้น เรียงตามลำดับเวลา ย่อหน้าละหนึ่งช่วงของเหตุการณ์
- ความเห็นของรายงาน: "รายงานเห็นว่า…" / "รายงานวิเคราะห์ว่า…" · ข้อเสนอแนะจริง: "คณะกรรมการแนะนำ…" (กฎ ช ใน DECISIONS)

## ข้อที่ไม่เปลี่ยน
- ป้ายย่อหน้า `[เหตุการณ์]` ฯลฯ และกฎ story format (DECISIONS หัวข้อ "เนื้อเรื่องเคส")
- ระดับความแน่นอนของ JTSB คงคำญี่ปุ่น 8 คำในวงเล็บไว้ เช่น "(推定)" เพราะแอปแปลงเป็นป้ายไทยพร้อมแถบให้เอง
  (ตารางใน DECISIONS) ห้ามแปลเป็นคำไทยในข้อมูล ส่วนคำญี่ปุ่นอื่นห้ามมี
- `ref`, `hfacs` และกฎ ก–ฑ
